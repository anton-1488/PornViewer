# PornViewer 2.0

Программа с открытым исходным кодом для просмотра adult-контента.
Разработана специально для доступа к различным порно-сайтам.
Я постарался соблюсти 3 принципа:

- Удобство
- Безопасность
- Анонимность

## Безоапсность и Анонимность

Приложение шифрует как скачанные фото/видео, так и системные файлы, такие как база данных.
Безопасность в интернете достигается путем возможности подключения прокси или
использование встроенного[tor-клиента](https://github.com/plovdev/orchid).

Для хранения ключей используется системное хранилище ключей
и моя библиотека [Keyer](https://github.com/plovdev/Keyer).
Кстати, при первом запуске у вас сгенерируется уникальный мастер-ключ, которым будут шифроваться и расшифровыватся все
файлы.
И это будет работать только на вашей машине.
Никакого скрытого поедения. Никаких звонков домой. Никакой истории. Макс имальная анонимность.

## Features

Подобное приложение, как и любое другое, должно быть удобным в использовании, и покрывать большую часть user-фич:

- Приятный минималистичный дизайн, с поддержкой нескольких тем.
- Поддержка почти любых сайтов через плагины-адаптеры(.pvva).
- Возможность работы с флешки.
- Функция глубокого поиска видео.
- Удобное увелечительное стекло, которое можно активировать при просмотре видео.
- Гибкие настройки и кастомизации.
- Deeplink'и
- Возможность делать upscale видео прямо во время просмотра, или ИИ-обработка через ffmpeg.

Это лишь основная часть фич, которые есть на данный момент.

## Использование

PornViewer легко использовать - скачал и запустил)
На странице релизов необходимо скачать версию PornViewer-2.x+ под вашу платформу.
Затем установить через установщик, после чего приложение появится на рабочем столе.

Так же можно скачать .jar файл - для этого нужно установить Java 25+.
Или вы можете склонировать репозиторий https://github.com/plovdev/PornViewer и запустить из среды разработки.
Можно внести какое-то изменения в код и запускать свою версию.

PornViewer поддерживается на следующий ОС:

- Windows 7 и выше.
- macOS и выше.
- Частично на unix-системах. Но я официально там не тестили(см. ветку pv-linux)

Программе не нужно мощное железо, много памяти или современная видеокарта.
Я писал его на `MacBook Air 2012(macOS 10.15) с Intel Core i7 Duo, 8GB DDR3 и Intel HD Graphics 4000`.

## PVVA(PornViewer Video Adapter)

Плагины, которые предоставляют доступ к тому или иному порно-сайту.
Разработчик может почтать про них более подробно [тут](https://github.com/plovdev/pvva).
Для обычного пользвателя все проще:
Это набор ссылок на нужные страницы сайта и lua код для парсинга этих страниц.
Так же он содержит конфигурацию для настроек http клиента, которая по мнению разработчика лучше всего подойдет для этого
сайта.

Lua код выполняется в изолированной песочнице и не может навредить вашей системе,
а ссылки строятся относительно base url, который вы можете проверить, прежде чем подключить плагин.
Если есть сомнения - активируйте прокси перед подключением адаптера.

## Пару слов про PornViewer 2.0

PornViewer 2.0 разрабатыватся в основной ветке main.
На данном этапе приложение в стадии переписывания, потому что до этого был PornViewer 1.x
архитектура которого устарела и ее трудно развивать(плюс там много ущербного кода).
PornViewer 1.x будет доступен и поддерживаться в ветку pv-legacy, до момента пока PornViewer 2.0 не выйдет полностью.

Ну и да, PornViewer 2 еще **не переписан полностью**, поэтому следите за обновлениями.
